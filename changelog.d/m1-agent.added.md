- `@muonhub/agent` (spec 0087): the headless Node.js 24 daemon replaces the first-attempt agent core. Serial ingest by stable `/dev/serial/by-id` path (`serialport`) or the virtual detector, with robust framing (CRLF/LF/CR, fragments, concatenated `COSMIC` records split as in v5, lossy UTF-8 with the raw bytes kept), reconnect with backoff, and a serial-silence watchdog ("device silent" is not "disconnected" and never produces zero-count minutes). Every raw line is committed to SQLite (`node:sqlite`, append-only layer 0) in batches before anything is derived; only complete minutes are recorded (partial first/last minutes discarded and counted); dead time comes from the device's cumulative counter; sessions end on reset, clock step, loss, configuration change, storage error; crash recovery closes open sessions and rebuilds hour summaries from the local minutes. A durable outbox uploads minutes, hour summaries and session records in order with one write in flight per kind, classifies transient / unknown (read-back before retry) / permanent outcomes, pauses instead of parking when the session is signed out, and parks rejected items without blocking later ones. Local web panel on `127.0.0.1` (token file, Host/Origin/CSRF checks, setup wizard, outbox retry/export), raw mirror (daily log and Unix socket), `muonhub-agent capture`, the v5 compatibility WebSocket bridge, a hardened systemd unit, and an Ubuntu x64 installer that verifies the Node bundle checksum. See `docs/operations/AGENT.md`.
