Data layer v2 in `packages/data-provider` (`v2` namespace): a `DataProviderV2` interface split by responsibility, a Firebase implementation (Firestore for metadata and summaries, a flat Realtime Database for minutes, the live window and status) and an in-memory implementation for consumer tests. Minutes are write-once with cursor-paginated range reads, the live window is pruned by time with unique keys, invalid stored records are returned as quarantine counts, and no Cloud Storage API exists.
