# Specifications

Every unit of implementation work follows a spec in `specs/NNNN-slug/spec.md`, written with the
template in [`docs/process/templates/spec.md`](../docs/process/templates/spec.md) and approved as part
of its milestone's step plan ([`docs/process/WORKFLOW.md`](../docs/process/WORKFLOW.md)).

## Numbering

- **0001–0077 — first v6 attempt (June 2026), superseded.** Kept as a historical record: they
  document what was built, the reasoning at the time, and the acceptance criteria. Each carries a
  "Superseded" banner. Their code remains on `main` until the rebuild replaces it, milestone by
  milestone. Known defects of that code are recorded in
  [`docs/audit/2026-10-02-V6-RESET-SESSION-RECORD.md`](../docs/audit/2026-10-02-V6-RESET-SESSION-RECORD.md).
- **0078–0082** were drafted on branches that are now archived as git tags
  (`archive/spec-0078-…` to `archive/spec-0082-…`); their useful ideas live in
  [`docs/product/BACKLOG.md`](../docs/product/BACKLOG.md).
- **0083 onward — the v6 rebuild.** Numbers are assigned when a spec is written.
