# Archive

Historical documents, kept **intact** for reference. They describe earlier plans and earlier code;
they are **not** current guidance. Current documentation starts at [`docs/README.md`](../README.md).
Archived documents keep their original language and names (some are in Spanish; some use the earlier
names MunHub / MunHub Lab).

| Folder | Contents |
|---|---|
| [`planning/`](planning/) | The June 2026 planning corpus of the first v6 attempt: master plan with the decision log D1–D46, architecture, data model, backlog, and topic plans 05–20. The decision log's current status is tracked in [`docs/decisions/README.md`](../decisions/README.md). |
| [`first-attempt/`](first-attempt/) | Architecture, data model, and technical index of the first v6 attempt's code. |
| [`v5/`](v5/) | The behavioral reference of v5 (needed for the v5 → v6 migration milestone). The v5 code itself lives on the `v5-production` branch. |
